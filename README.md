# 💬 Customer Review Sentiment Analysis Pipeline

📖 About

This project demonstrates a production-grade, end-to-end Machine Learning workflow and software deployment for analyzing customer review datasets and predicting sentiment (Recommended vs. Not Recommended). The pipeline handles core real-world challenges such as high-dimensional sparse text data and severe class imbalance, utilizing strict data leakage prevention, hyperparameter tuning via GridSearchCV, and Youden's J statistic for optimal decision thresholding. Finally, the optimized master pipeline is serialized for real-world production deployment using Joblib.

🚀 Technologies

- Python
- Pandas & NumPy
- Scikit-Learn (Pipelines, ColumnTransformer, Logistic Regression)
- Imbalanced-Learn (SMOTE)
- Joblib (Model Serialization)
- Matplotlib & Seaborn

📂 Dataset

The dataset consists of real-world customer reviews containing textual feedback and metadata. Due to the inherent nature of customer feedback, the dataset suffers from severe class imbalance (heavily skewed toward positive reviews). The pipeline processes unstructured text using `CountVectorizer` and normalize numerical features to prepare data for supervised classification.

📊 Project Workflow

1. **Data Preprocessing & Imputation:** Handling missing values and preparing structured features safely.
2. **Text Vectorization:** Transforming raw review text into numerical matrices using `CountVectorizer`.
3. **Class Balancing:** Applying `SMOTE` strictly within cross-validation folds to prevent synthetic data leakage.
4. **Pipeline Architecture:** Encapsulating preprocessing, vectorization, oversampling, and modeling into a single cohesive `imblearn` pipeline.
5. **Hyperparameter Optimization:** Utilizing `StratifiedKFold` and `GridSearchCV` to optimize for `roc_auc`.
6. **Threshold Tuning:** Shifting from the naive 0.5 threshold to an optimal decision threshold using Youden's J statistic.
7. **Model Explainability & Serialization:** Extracting logistic regression coefficients to interpret vocabulary drivers and serializing the model using `joblib`.

📈 Model Performance & Evaluation

To evaluate the classification models while mitigating class imbalance bias, the **ROC-AUC** metric was prioritized alongside Precision, Recall, and F1-Score during the grid search evaluation.

| :--- | :--- | :--- |
| Baseline Pipeline | Default Settings | ~0.8500 |

🏆 Why Logistic Regression & Pipeline Architecture?

In text classification tasks involving high-dimensional sparse matrices (generated by `CountVectorizer`), linear models like **Logistic Regression** combined with L2 regularization ($C = 0.1$) offer exceptional computational efficiency, rapid convergence, and high interpretability. 

**Business & Technical Highlights:**
- **Leakage Prevention:** By forcing all transformers and oversamplers inside cross-validation folds, we guaranteed 0% data leakage from the test set.
- **Decision Boundary Tailoring:** Shifting the threshold to 0.6170 proved essential for capturing critical customer complaints without degrading overall system precision.
- **Production-Ready Artifacts:** The finalized model was fully serialized into `sentiment_pipeline_model.joblib`, bridging the gap between exploratory data science and scalable software integration.
